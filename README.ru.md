# Lumen

Стеклянная музыкальная капсула для Windows 11. Стоит над панелью задач,
показывает, что играет, и даёт панели задач, колесу мыши и Discord осмысленную
работу с этим.

[English version](README.md) · [Архитектура](ARCHITECTURE.md)

## Возможности

- **Капсула над панелью задач.** Подложка DWM Acrylic/Mica, раскрывается при
  наведении и на смене трека, перетаскивается куда угодно, магнитится к углам.
- **Любой плеер.** Читает системную медиасессию Windows (SMTC), поэтому Spotify,
  браузеры, foobar2000 и всё остальное работают без интеграции.
- **Громкость колесом на панели задач.** Прокрутка над кнопкой приложения меняет
  громкость *этого приложения*. Именно её слышно на стриме и в записи: общий
  регулятор применяется уже после захвата звука.
- **Усиление громкости выше 100% и усиление басов.** Windows ограничивает любую
  регулировку единицей; Lumen захватывает играющее приложение, убавляет его до
  2% и вместо него воспроизводит обработанную копию. Добавляет ~30 мс задержки,
  пока работает.
- **Закрытие приложения с панели задач.** Средний клик по его кнопке.
- **Синхронизированный текст песни.** LRCLIB с запасным источником Genius,
  караоке-заливка и живой слайдер синхронизации. По умолчанию выключено —
  единственная функция, которая использует сеть.
- **Спектр.** 16 полос с логарифмическим шагом из захвата WASAPI loopback,
  работает только когда панель открыта и музыка играет.
- **Discord Rich Presence.** Настоящая обложка, время, кнопки-ссылки, фильтр по
  плеерам.
- **Умная пауза.** Пауза при блокировке, возобновление при разблокировке — и
  только то, что поставил на паузу сам.
- **Карточка трека.** PNG 1200×600 с текущим треком сразу в буфер обмена.
- **Окно настроек** на русском и английском, с обучением при первом запуске.
- **Клод.** Пиксельный краб, который танцует в капсуле, пока играет музыка, и
  останавливается по клику. По умолчанию выключен: это пасхалка, а не функция.
- **Портативность.** Один exe на 4,3 МБ и один JSON рядом с ним. Без
  установщика и без реестра, кроме необязательной записи автозапуска.

## Быстрый старт

```bash
npm install
npm run release
```

Портативный exe появится в `src-tauri/target/release/lumen.exe`. Скопируйте его
куда угодно: при первом запуске он создаст рядом `lumen.config.json` и покажет
короткое обучение.

Разработка:

```bash
npm run start
```

`npm start` поднимает Vite и хост вместе. Обычный `cargo build` даёт
самодостаточный бинарник, потому что `custom-protocol` включён по умолчанию, а
`npm start` передаёт `--no-default-features`, чтобы использовался dev-сервер.

## Тесты

```bash
cd src-tauri && cargo test        # 130 тестов хоста
cargo clippy --all-targets        # без предупреждений
npm run check                     # типы рендерера
npm run check:motion              # совпадение кривых хоста и рендерера
```

Семь тестов помечены `#[ignore]`, потому что им нужен реально играющий звук или
настоящая блокировка экрана:

```bash
cargo test --lib -- --ignored --nocapture the_tap_follows   # захват против громкости сессии
cargo test --lib -- --ignored --nocapture boost_replaces    # вся цепочка усиления
cargo test -- --ignored --nocapture spectrum_cost           # стоимость спектра по CPU
cargo test -- --ignored genius                              # парсер Genius ещё живой
```

## Как устроено усиление

В Windows нет регулятора громкости выше 100%: и `ISimpleAudioVolume`, и
`IAudioEndpointVolume` принимают значение в диапазоне `0..=1`. Громче — только
обработкой сэмплов.

1. Захват звука приложения через process loopback
   (`ActivateAudioInterfaceAsync`, `PROCESS_LOOPBACK_MODE_INCLUDE_TARGET_PROCESS_TREE`).
2. Приложение убавляется до 2% — **не** заглушается. Точка захвата находится
   *после* громкости сессии, поэтому заглушённое приложение отдаёт тишину; это
   измеряет `loopback::tests::the_tap_follows_the_session_volume`, наблюдаемое
   отношение — 0,0207.
3. Обратное умножение на 50, затем усиление, полка 120 Гц и лимитер с мягким
   коленом, чтобы пики сжимались, а не срезались.
4. Вывод на устройство по умолчанию.

Оставшийся оригинал играет на 34 дБ тише усиленной копии — неслышно, тогда как
дубль на полной громкости давал бы явное эхо. Громкость приложения
восстанавливается при выключении усиления, при выходе из Lumen и по
Alt + средний клик.

## Настройки

`lumen.config.json` рядом с exe. Если каталог только для чтения, используется
`%APPDATA%\Lumen\`; подсказка в трее говорит, какой путь выбран. Всё это есть и
в окне настроек.

| `uiScale` | `0.75`–`2.0` | Масштаб интерфейса поверх DPI монитора |
| `dock` | `taskbar-center` \| `bottom-left` \| `bottom-right` \| `top-left` \| `top-right` \| `free` | |
| `backdrop` | `auto` \| `acrylic` \| `mica` | Применяется при запуске |
| `shape` | `round` \| `square` | |
| `monitor` | `primary` \| `cursor` | |
| `alwaysExpanded` | bool | Держать панель раскрытой |
| `showWhilePaused` | bool | |
| `autoExpandOnTrackChange`, `autoExpandMs` | bool, мс | |
| `volumeStep` | `0.01`–`0.1` | На один щелчок колеса |
| `boost.enabled`, `boost.gain`, `boost.bassDb` | bool, `0.5`–`3.0`, `-12`–`12` | См. выше |

### Горячие клавиши

По умолчанию F5/F6/F7 слева направо — в том же порядке, что и кнопки на экране.
Остальное не назначено: любое значение по умолчанию отнимает клавишу у того, что
пользователь мог назначить сам.

| Ключ | Действие | По умолчанию |
|---|---|---|
| `hotkeys.previous` | Предыдущий трек | `F5` |
| `hotkeys.playPause` | Воспроизведение / пауза | `F6` |
| `hotkeys.next` | Следующий трек | `F7` |
| `hotkeys.cycleSession` | Переключиться на следующий играющий плеер | `Ctrl+F6` |
| `hotkeys.volumeUp` / `volumeDown` | Громкость играющего приложения | — |
| `hotkeys.repeat` | Режим повтора плеера | — |
| `hotkeys.toggleVisible` | Скрыть или показать капсулу | — |
| `hotkeys.togglePinned` | Держать панель открытой | — |

Принимается и `Ctrl+KeyA`, и сокращение `ctrl+a`. Сочетание, уже занятое другой
программой, пишется в лог и пропускается — остальные продолжают работать.

### Настройка Discord

Статус публикуется *от имени* приложения Discord, поэтому нужен ID, и разумного
значения по умолчанию нет: общий ID поставил бы чужое имя в ваш профиль.

1. Создайте приложение на <https://discord.com/developers/applications>. Его имя
   и отображается после «Слушает».
2. Скопируйте Application ID в настройки → Discord.
3. В разделе Rich Presence → Art Assets загрузите картинку с именем `lumen` —
   это запасное изображение и маленький значок на обложке.

Кнопки никогда не видны в вашем собственном профиле — их видят только другие, —
и Discord рисует их только для активности типа *Playing*. `discord.activity` —
это и есть выбор между полосой прогресса и кнопками.

## Жесты мыши

| Жест | Действие |
|---|---|
| Колесо над панелью задач | Громкость приложения под курсором |
| Колесо над капсулой | Громкость играющего приложения |
| Средний клик по кнопке на панели задач | Закрыть это приложение |
| Средний клик по капсуле | Скрыть до следующего трека |
| Alt + средний клик по капсуле | Немедленно завершить этот экземпляр |
| Ctrl + колесо | Крупный шаг громкости (×5) |
| Shift + колесо | Точный шаг громкости (×¼) |
| Клик по полосе громкости | Подсказывает про колесо и модификаторы — сама полоса только показывает уровень |
| Клик по Клоду | Танцевать или отдыхать |
| Перетаскивание капсулы | Перенести; рядом с углом примагнитится |

Alt + средний клик выходит кратчайшим путём и ничего не записывает по дороге. При
этом он всё равно возвращает громкость приложению, которое убавило усиление.

## Что это стоит

Измерено на машине разработки, а не прикинуто:

| | |
|---|---|
| Портативный exe | 4,31 МБ |
| CPU, ничего не играет | 0,00% — нигде нет опроса: SMTC, хук мыши и блокировка экрана событийные |
| CPU, играет, капсула свёрнута | ~0,5% одного ядра — одно событие таймлайна SMTC в секунду и часы, которые оно двигает |
| CPU со спектром | +0,043% машины (0,52% одного ядра) |
| CPU с усилением | один поток захвата и один вывода на 48 кГц |
| Память, процесс хоста | 33 МБ working set, 7 МБ private |
| Память с WebView2 | ~200 МБ private, 405–476 МБ working set по всему дереву процессов |

Цифра по памяти — это нижняя граница WebView2, а не данные Lumen: два WebView
(капсула и настройки) с деревом процессов браузера позади. Исходное требование
было «меньше 20 МБ»; с рендерером на WebView это недостижимо, и `ARCHITECTURE.md`
§3 описывает, что было испробовано.

## Требования

- Windows 10 1809+ (для Mica нужна Windows 11 22H2, ниже — Acrylic, ещё ниже —
  простая полупрозрачная панель). Усилению нужна Windows 10 2004+ ради process
  loopback.
- Среда WebView2 — предустановлена в Windows 11.
- Для сборки: Rust 1.85+, Node 20+, набор инструментов MSVC.
